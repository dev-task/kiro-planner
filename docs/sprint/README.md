# スプリントディレクトリ

このディレクトリは、スプリント運用に関するドキュメントを保存する場所です。

## ディレクトリ構造

```
docs/sprint/
├── README.md                                # このファイル
├── {project}-sprint-{number}-plan.md        # スプリント計画
├── {project}-sprint-{number}-review.md      # スプリントレビュー
└── {project}-sprint-{number}-retro.md       # レトロスペクティブ
```

## スプリント運用フロー

### 1. スプリント計画

**Hook**: "🎯 スプリント計画" を実行

**生成ファイル**: `{project}-sprint-{number}-plan.md`

**内容**:

- スプリントゴール
- 選択したPBI一覧
- タスク分解
- 担当者アサイン
- ベロシティ計画

### 2. スプリント実行

開発チームがPBIを実装し、Notionでステータスを更新。

### 3. スプリントレビュー

**実行**: `@sprint-agent` でレビュー実施

**生成ファイル**: `{project}-sprint-{number}-review.md`

**内容**:

- 完了したPBI
- 未完了のPBI
- ベロシティ実績
- デモ内容

### 4. レトロスペクティブ

**Hook**: "🔍 スプリントレトロスペクティブ" を実行

**生成ファイル**: `{project}-sprint-{number}-retro.md`

**内容**:

- Keep（続けること）
- Problem（問題点）
- Try（改善アクション）
- 改善アクションPBI

## スプリント計画例

```markdown
# Sprint 1 計画: プロジェクト名

## スプリント情報

- スプリント番号: 1
- 期間: 2024-01-01 〜 2024-01-14（2週間）
- チームベロシティ: 20pt
- チームメンバー: 5名

## スプリントゴール

MVP機能の基本実装を完了し、ユーザーが基本的な操作を行えるようにする。

## 選択したPBI

| ID      | タイトル         | タイプ     | SP  | 担当 | ステータス |
| :------ | :--------------- | :--------- | :-- | :--- | :--------- |
| PBI-001 | ユーザー登録機能 | User Story | 5   | 田中 | To Do      |
| PBI-002 | ログイン機能     | User Story | 3   | 佐藤 | To Do      |
| PBI-003 | プロフィール編集 | User Story | 5   | 鈴木 | To Do      |
| PBI-004 | データベース設計 | Task       | 3   | 高橋 | To Do      |
| PBI-005 | API設計          | Task       | 3   | 渡辺 | To Do      |

**合計**: 19pt

## タスク分解

### PBI-001: ユーザー登録機能

- [ ] UI設計（1h）
- [ ] フロントエンド実装（4h）
- [ ] バックエンドAPI実装（4h）
- [ ] バリデーション実装（2h）
- [ ] テスト作成（3h）
- [ ] レビュー（1h）

## リスク

- データベース設計の遅延がAPI実装に影響する可能性
- 外部API連携の仕様確認が必要

## 次のアクション

- [ ] キックオフミーティング
- [ ] デイリースタンドアップ開始
- [ ] 進捗の可視化（バーンダウンチャート）
```

## レトロスペクティブ例

```markdown
# Sprint 1 レトロスペクティブ: プロジェクト名

## Keep（続けること）

- ✅ デイリースタンドアップが効果的だった
- ✅ ペアプログラミングでコード品質が向上
- ✅ 早めのコードレビューで手戻りが減少

## Problem（問題点）

- ❌ 見積もりが甘く、一部のPBIが未完了
- ❌ 外部API仕様の確認に時間がかかった
- ❌ テスト環境の不安定さで開発が遅延

## Try（改善アクション）

- 🔄 見積もり時にバッファを10%追加
- 🔄 外部依存は事前に確認する
- 🔄 テスト環境の安定化タスクを追加

## 改善アクションPBI

以下のPBIをバックログに追加：

- [改善] 見積もりプロセスの改善（3pt）
- [改善] テスト環境の安定化（5pt）
- [改善] 外部API仕様確認チェックリスト作成（2pt）

## ベロシティ

- 計画: 19pt
- 完了: 16pt
- 達成率: 84%
- 次回計画: 17pt（平均ベロシティ × 0.9）
```
